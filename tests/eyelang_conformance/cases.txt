# Eyelang conformance cases, one per normative statement of
# docs/eyelang-specification.md. `[intent]` records what the specification
# requires; `[output]` is the expected result document (Eyelang result
# format 2) or, with `[error]`, a substring of the expected error message.
#
# Every expectation here is also produced by the reference implementation
# (`eyelang`), so a case that fails names a divergence rather than a
# preference. Regenerate the expectations with:
#
#     scripts/eyelang-conformance --update



[case] lexical/comment-runs-to-end-of-line
[section] 2
[intent] a `#` comment outside a string runs to the end of the line and is otherwise insignificant
[program]

[output]
