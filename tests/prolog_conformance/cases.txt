# Prolog conformance cases, one per normative statement of
# docs/prolog-specification.md. `[intent]` records what the specification
# requires; `[output]` is the expected result document or, with `[error]`,
# a substring of the expected error message.
#
# Because the language is ISO/IEC 13211-1 Prolog and not a local
# invention, most of these cases can be held against an external
# authority. `scripts/prolog-conformance` runs every case that stays
# inside the pure subset through SWI-Prolog, GNU Prolog, SICStus and
# Scryer as well, and reports any divergence:
#
#     scripts/prolog-conformance
#
# Regenerate the `[output]` blocks after an intended change with:
#
#     scripts/prolog-conformance --update
